# Sales-Analysis-Management-System-SQL-Project-
This SQL project analyzes sales performance across regions, customers, products, and salespersons. I designed a normalized database, inserted realistic business data, and wrote SQL queries to extract meaningful business insights.

#Project Features
1. 5-table normalized relational database
2. 200+ realistic sales records
3. Analytical queries using joins, aggregations, and date functions
4. Business insights based on revenue, regions, categories, customers
5. Ready for visualization in Power BI / Tableau

#Database Schema
Tables:
  Regions
  Salespersons
  Customers
  Products
  Sales

#Key SQL Queries
1. Total Revenue
2. Monthly Revenue Trend
3. Best Region
4. Top Products (Revenue + Units)
5. Best Salesperson
6. Category Performance
7. Customer Purchase Frequency
8. Region-Product Matrix
9. Average Order Value
